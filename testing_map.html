Writeup and code for analysis


Welcome to the Chicago Megatrail Project


This is a map of the largest connected network of sidewalks, bike/pedestrian trails, and crosswalks in the Chicagoland region!


I've also included some analysis of the map data in the column to the left. For more information on what those bar graphs are measuring, click the "Writeup for Code and Analysis" link in the top!


If you would like to highlight a community on the map, either click the bar for the community in one of the graphs to the left, or click the community on the map itself.


If you're trying to use this site for navigation and you'd like to see your current position, just click "show current location."


If you're doing that and the marker isn't showing up, be sure to allow the site to access your location. Your location information is not stored on my end.
